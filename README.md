# Portfolio Miguel Souop - Cyberpunk Edition 🚀

Portfolio professionnel moderne avec un design futuriste cyberpunk utilisant des couleurs néon violet, rose et bleu électrique.

## 🎨 Caractéristiques

- **Design Cyberpunk/Futuriste** : Effets néon, animations glow, ambiance sombre et lumineuse
- **Responsive** : Adapté à tous les écrans (mobile, tablette, desktop)
- **Sections complètes** :
  - Hero Section avec présentation et CTA
  - À propos
  - Compétences (catégorisées)
  - Services
  - Projets
  - Contact avec formulaire fonctionnel
- **Animations fluides** : Effets hover, transitions, animations subtiles
- **Performance optimisée** : React + TailwindCSS

## 🛠️ Technologies

- **React.js** : Framework JavaScript
- **TailwindCSS** : Framework CSS utility-first
- **Lucide React** : Icônes modernes
- **Google Fonts** : Typographies Orbitron & Rajdhani

## 📦 Installation

1. Installer les dépendances :
```bash
npm install
```

2. Lancer le serveur de développement :
```bash
npm start
```

3. Ouvrir [http://localhost:3000](http://localhost:3000) dans votre navigateur

## 🚀 Build Production

```bash
npm run build
```

## 📝 Personnalisation

### Couleurs
Les couleurs cyberpunk sont définies dans `tailwind.config.js` :
- `cyber-purple` : #a855f7
- `cyber-pink` : #ec4899
- `cyber-blue` : #3b82f6

### Contenu
Modifiez le contenu dans les composants situés dans `src/components/`

### Images des projets
Remplacez les URLs d'images dans `src/components/Projects.js`
